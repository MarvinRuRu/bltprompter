## Блю суфлер

### 📝 Описание проекта
Суфлер с поддержкой блютус кнопки

### 🏗️ Функционал

* работа от блютус кнопки
* регулировка размера шрифта, скорости текста
* возможность постраничного вывода
* постраничный вывод с абзацев
* зеркальное отображение текста
* промотка в обратном направлении
* сохранение текстов в библиотеку
* чтение fb2, epub, pdf, txt
