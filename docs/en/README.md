## Bluetooth prompter

### 📝 Project Description
Prompter with bluetooth button support

### 🏗️ Features

* adjust font size, text speed
* work from Bluetooth button
* supports pagination
* pagination starting from paragraphs
* mirror text
* scroll backwards
* save texts to library
* reading fb2, epub, pdf, txt
